Configuration Guide

Setting up SAML with Okta
  1. In Okta Admin Console, go to Applications > Create App Integration
  2. Select SAML 2.0 and click Next
  3. Enter app name and upload logo (optional)
  4. Enter the SSO URL and Entity ID from NeoZen
  5. Configure attribute statements
  6. Download the IdP metadata or copy the SSO URL and certificate
  7. Add the provider in NeoZen using the IdP metadata
Setting up OIDC with Azure AD
  1. In Azure Portal, go to Azure Active Directory > App registrations
  2. Click New registration
  3. Enter a name and select supported account types
  4. Add the NeoZen redirect URI
  5. Copy the Application (client) ID and Directory (tenant) ID
  6. Create a client secret under Certificates & secrets
  7. Add the provider in NeoZen using these credentials
Setting up OIDC with Google Workspace
  1. Go to Google Cloud Console > APIs & Services > Credentials
  2. Click Create Credentials > OAuth client ID
  3. Select Web application
  4. Add authorized redirect URIs
  5. Copy the Client ID and Client Secret
  6. Add the provider in NeoZen using these credentials
