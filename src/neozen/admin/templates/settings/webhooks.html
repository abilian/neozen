Real-time Event Notifications

Webhooks allow you to receive HTTP POST requests when events occur in NeoZen. Use them to integrate with your systems.

No webhooks configured

Add a webhook endpoint to receive event notifications.

Available Events

user.created

A new user was created

user.updated

User profile was updated

user.deleted

A user was deleted

session.created

User logged in

session.revoked

Session was revoked

mfa.enabled

User enabled MFA

password.changed

Password was changed

role.assigned

Role assigned to user

role.revoked

Role removed from user

Payload Format

{
  "id": "evt_123456789",
  "type": "user.created",
  "timestamp": "2024-01-15T10:30:00Z",
  "data": {
    "user_id": "usr_abc123",
    "email": "user@example.com",
    "created_at": "2024-01-15T10:30:00Z"
  }
}

Webhooks include a X-Webhook-Signature header for verification using HMAC-SHA256.
