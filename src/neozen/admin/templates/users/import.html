CSV Format

Your CSV file should have the following columns:

  • email - Required. User's email address.
  • username - Optional. Letters, digits, dot, dash, underscore.
  • is_active - Optional. true/false (default: true)
  • is_verified - Optional. true/false (default: false)

Tip: run a dry run first to preview what will happen before applying.

Sample CSV

email,username,is_active,is_verified
alice@example.com,alice,true,true
bob@example.com,bob,true,false
charlie@example.com,,false,false
